Repository & access
Isolated per visitor: users/<identity>/fairs/<fairId>/. Everyone writes only to their own namespace, so nobody overwrites anyone else.
Test connection fills in your GitHub username automatically; leave this blank in normal use.
The token is stored in plain text in this browser. Use a fine-grained token limited to this one private repo.
Cloud encryption (optional)
PBKDF2-SHA256 (100k rounds) + AES-GCM-256; the key is never uploaded. Records and photos are encrypted, meta.json (counts and salt) stays in plain text.
The passphrase is not stored in the cloud — lose it and the cloud copy cannot be recovered. Local data is unaffected.
Access control
The app code lives in a public repository (GitHub Pages, readable by anyone); factory data goes only to a private repository. Visibility is checked before every upload — writes to a public repo are always refused, and the app repo itself is blocked too.
To let a colleague read your data, add them as a Collaborator on the private repo. To let them record their own, have them point at the same private repo: their data lands in their own namespace.

Fair defaults
Photos & camera roll
A web page cannot write to the camera roll directly. On iOS the share sheet opens after each shot — pick Save to Photos once; on Android / desktop the file is saved silently to Downloads and usually shows up in the gallery.
Photos picked from the gallery are not saved twice. Any single photo can still be saved with the ⬇ button in its top-right corner.
Scoring weights (must add up to 100%)
Each dimension is scored 1–5 stars and the weights must add up to 100%. Presets can still be fine-tuned — remember to tap Save. Weights travel with the backup, so other devices match after syncing.
About
This device is always the first copy: entries go to IndexedDB first and work offline; the cloud copy is written to your own private GitHub repo when you tap backup or the timer fires.
Install the PWA on another device and sign in with the same GitHub token and the same private repo, then tap Pull all fairs from cloud to see the same content.
Even so, uninstalling the PWA or clearing site data still loses everything — keep both a ZIP export and a cloud backup.
