备份策略
自动备份默认只传元数据（几十 KB）；照片建议回酒店有 Wi-Fi 时手动全量备份。
同步动作
按展会 ID 精确匹配——只适用于两端已经存在同一个展会。 换设备拉电脑端数据，请用下面的「📥 拉取云端全部展会」。
换设备时：装好 PWA → 这里填同一个 GitHub 账号的 token 和同一个私有仓 → 点「拉取云端全部展会」，展会与记录就都过来了。同一条记录以最后修改时间为准， 两边都改过则保留时间更晚的那份。
仓库与访问控制
按访问者隔离：users/<身份>/fairs/<展会ID>/。 每个人只写自己的命名空间，互不覆盖。
正常情况下「测试连接」会自动填入 GitHub 用户名，这一栏留空即可。
token 明文存在本机浏览器里，用 fine-grained token 并只授权这一个私有仓库。
云端加密（可选）
PBKDF2-SHA256 十万轮派生 + AES-GCM-256，密钥不上传；只加密记录与照片， meta.json（统计数字与 salt）保持明文。
口令不保存在云端，忘记后云端数据无法恢复——本机数据不受影响。
访问控制
程序代码在公开仓库（Pages 站点，任何人可读），供应商数据只进私有仓库。 上传前会校验可见性；公开仓库一律拒绝写入，程序仓库也会被直接拦下。
要让同事看到自己的数据：把他加为私有仓库的 Collaborator； 要让他录自己的数据：让他填同一个私有仓库，数据落在他自己的命名空间下。

照片与系统相册
网页不能自己写进相册，只能：苹果拍完自动弹系统分享面板，选一次「存储到照片」即进相册； 安卓 / 电脑静默存到「下载」目录，相册里通常直接可见。

关于
本机永远是第一副本：录入先写本地 IndexedDB，离线可用；云备份只是在您点击或定时器到期时 写入自己的私有 GitHub 仓库。
在另一台设备（或电脑）上装好本 PWA，用同一个 GitHub 账号的 token 和同一个私有仓登录， 点「拉取云端全部展会」即可看到同样的内容。
即便如此，卸载 PWA、清理网站数据仍会丢数据，导出 ZIP 与云备份请各留一份。
